# Changelog

## 0.2.0
- Admins can make other people admins, and take it away. Nobody can change their own role.
- Install guide for iPhone and Android (`/install`), with prompts on the join page, Open screen and Settings.
- Invite card copies a complete message (link plus code), with a Share button.
- Setup page links each step to the setup guide, and explains the setup password.
- Fixed: about 1 in 256 generated push keys was a byte short and broke notifications.
- Settings shows when a newer version is available.
- Updates: a weekly GitHub Action opens a pull request with the latest Knock in your repository, and `scripts/sync-upstream.sh` does the same by hand.
